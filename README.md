# 🚦 Basic Traffic System Simulation
This is a simple graphical simulation of a basic traffic system developed using Python and Pygame. 
<br>
The system simulates a car moving along a horizontal road (represented by a line), stopping at a checkpoint when the traffic light is red and moving forward when it turns green.

## 🛠️ Features
Horizontal road represented by a single line.

A car continuously moves from left to right.

A traffic light (Red/Green) controls car movement.

Checkpoint before the traffic light.

The car stops automatically at the checkpoint if the light is red.

The car continues moving if the light is green.

The car loops back and keeps running infinitely.
